# NFT Marketplace

NFT Marketplace is a responsive marketplace-style frontend project completed through a virtual internship. The project focuses on API calls, routing, reusable components, and marketplace UI structure.

## Features

- NFT collection browsing
- Dynamic NFT detail pages
- API-based marketplace data
- Routing between pages
- Loading states
- Reusable card and layout components
- Responsive marketplace interface

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- API Integration
- Routing
- Responsive Web Design

## Challenges Solved

- Practiced fetching and rendering dynamic NFT data.
- Built marketplace-style routes for browsing and details.
- Created reusable UI components for NFT cards and sections.
- Managed loading states during API requests.
- Improved responsive layouts across different screen sizes.

## What I Would Improve Next

- Add search and filtering for NFT collections.
- Improve loading skeletons and empty states.
- Add stronger error handling for failed API calls.
- Improve accessibility for marketplace navigation.
- Add saved/favorite NFT functionality.

## Installation Instructions

```bash
git clone https://github.com/thientimothy-nguyen/nft-marketplace-virtual-internship.git
cd nft-marketplace
npm install
npm run dev
```
